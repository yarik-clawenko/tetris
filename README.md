# Тетрис 🎮

Классический тетрис на React + TypeScript.

![Tetris screenshot](https://img.shields.io/badge/React-18-blue) ![TypeScript](https://img.shields.io/badge/TypeScript-5-blue)

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:5173

## Управление

| Клавиша | Действие |
|---------|----------|
| ← → | Движение влево/вправо |
| ↑ | Поворот |
| ↓ | Ускорить падение |
| Space | Мгновенный сброс |
| P | Пауза |

## Особенности

- 7 классических фигур (I, O, T, S, Z, J, L)
- Прогрессивная сложность (скорость растёт с уровнем)
- Показ следующей фигуры
- Подсчёт очков и линий
- Адаптивный интерфейс

## Технологии

- React 18
- TypeScript
- Vite
- Custom hooks для логики игры
